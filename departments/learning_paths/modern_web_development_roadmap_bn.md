# আধুনিক ফুল-স্ট্যাক ওয়েব ডেভেলপমেন্ট ও রিয়েল-টাইম সিস্টেম আর্কিটেকচার রোডম্যাপ (১২ সপ্তাহ)
**বিভাগ:** কারিকুলাম অ্যান্ড লার্নিং পাথ বিভাগ, বাংলা রিসোর্স ফ্যাক্টরি (Bangla Resource Factory)  
**রিসোর্স আইডি:** `BRF-LRN-004`  
**রোডম্যাপ টাইটেল:** Modern Full-Stack Web Development & Real-Time Distributed Systems Architecture  
**টার্গেট অডিয়েন্স:** বাংলাভাষী সফটওয়্যার ডেভেলপার, ফ্রন্টএন্ড/ব্যাকএন্ড ইঞ্জিনিয়ার এবং কম্পিউটার সায়েন্সের শিক্ষার্থী  
**লক্ষ্য:** শিক্ষার্থীদের টাইপস্ক্রিপ্ট, আধুনিক নেক্সট.জেএস (Next.js App Router), রিলেশনাল ডাটাবেস ডিজাইন, ডিস্ট্রিবিউটেড ক্যাশিং, ওয়েব-সকেট ও মাইক্রোসার্ভিস আর্কিটেকচারে দক্ষ করে তোলা।

---

## 🧭 কারিকুলাম ওভারভিউ (Executive Summary)

ওয়েব ডেভেলপমেন্টের সংজ্ঞা গত কয়েক বছরে বৈপ্লবিকভাবে পরিবর্তিত হয়েছে। কেবল সাধারণ এইচটিএমএল/সিএসএস কিংবা সাধারণ ক্রুড (CRUD) অ্যাপ্লিকেশনে আধুনিক ইন্ডাস্ট্রি সন্তুষ্ট নয়। বর্তমান যুগে প্রয়োজন টাইপ-সেফটি (TypeScript), সার্ভার কম্পোনেন্টস (React Server Components), ডিস্ট্রিবিউটেড রিলেশনাল স্টোরেজ (PostgreSQL + Prisma/Drizzle), হাই-স্পিড ক্যাশিং (Redis), রিয়েল-টাইম ইভেন্ট স্ট্রিমিং (WebSockets / SSE) এবং স্কেলেবল ক্লাউড আর্কিটেকচার।

এই ১২ সপ্তাহের রোডম্যাপটি এমনভাবে ডিজাইন করা হয়েছে যাতে একজন শিক্ষার্থী আধুনিক সফটওয়্যার ইঞ্জিনিয়ারিংয়ের শ্রেষ্ঠ স্ট্যান্ডার্ডগুলো হাতে-কলমে শিখে সরাসরি ইন্ডাস্ট্রি-গ্রেড প্রজেক্ট তৈরি ও ডিপ্লয় করতে পারেন।

## 🗓️ ১২ সপ্তাহের পূর্ণাঙ্গ সিলেবাস ও ল্যাব রূপরেখা

### ⚡ ফেজ ১: আধুনিক টাইপস্ক্রিপ্ট ও অ্যাডভান্সড ফ্রন্টএন্ড আর্কিটেকচার (সপ্তাহ ১ - ৩)

#### সপ্তাহ ১: প্রোডাকশন টাইপস্ক্রিপ্ট (TypeScript) ও আর্কিটেকচারাল প্যাটার্ন
- **তাত্ত্বিক ভিত্তি:**
  - কেন JavaScript একা বড় প্রজেক্টে ব্যর্থ: Type Inference, Structural Subtyping।
  - Generics, Conditional Types, Mapped Types, Template Literal Types।
  - Type Narrowing, Discriminated Unions এবং Exhaustive Checks।
  - Runtime Validation বনাম Compile-time Validation: Zod ও ArkType এর গভীর প্রয়োগ।
- **হ্যান্ডস-অন ল্যাব:**
  - Zod এবং জেনেরিক টাইপস ব্যবহার করে সম্পূর্ণ টাইপ-সেফ এপিআই রেসপন্স পার্সার তৈরি।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `typed_api_sdk`: টাইপস্ক্রিপ্ট সমৃদ্ধ রিউজেবল এপিআই ক্লায়েন্ট এসডিকে।

#### সপ্তাহ ২: React 19 ও Next.js (App Router) ইন্টারনালস
- **তাত্ত্বিক ভিত্তি:**
  - Client Components বনাম Server Components (RSC): রেন্ডারিং লাইফসাইকেল ও বান্ডল সাইজ অপ্টিমাইজেশন।
  - Streaming SSR (`Suspense`), Progressive Hydration।
  - Server Actions: এপিআই রুট ছাড়া সরাসরি ডাটাবেস মিউটেশন ও অপটিমিস্টিক ইউআই (Optimistic UI)।
  - প্যারালাল রুট (`@modal`) এবং ইন্টারসেপ্টিং রুট (`(.)photos`) আর্কিটেকচার।
- **হ্যান্ডস-অন ল্যাব:**
  - Next.js App Router দিয়ে একটি রিয়েল-টাইম কন্টেন্ট ম্যানেজমেন্ট ড্যাশবোর্ড তৈরি।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `modern_nextjs_dashboard`: সার্ভার কম্পোনেন্টস ও স্ট্রিমিং ইউআই সমৃদ্ধ ড্যাশবোর্ড।

#### সপ্তাহ ৩: আধুনিক স্টেট ম্যানেজমেন্ট ও ইউআই ডিজাইন সিস্টেম
- **তাত্ত্বিক ভিত্তি:**
  - সার্ভার স্টেট বনাম ক্লায়েন্ট স্টেট: কেন Redux এর বদলে TanStack Query (React Query) ব্যবহার করবেন।
  - ক্যাশ ইনভ্যালিডেশন, ব্যাকগ্রাউন্ড রিফেচিং এবং অফলাইন সিঙ্ক।
  - গ্লোবাল ক্লায়েন্ট স্টেট: Zustand ও Jotai।
  - Tailwind CSS v4, Radix UI ও Shadcn/UI: অ্যাক্সেসিবল (a11y) কম্পোনেন্ট সিস্টেম ডিজাইন।
- **হ্যান্ডস-অন ল্যাব:**
  - Shadcn/UI ও Zustand দিয়ে সম্পূর্ণ অ্যাক্সেসিবল ও রেসপনসিভ কম্পোনেন্ট লাইব্রেরি তৈরি।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `accessible_component_system`: কাস্টমাইজেবল ডার্ক মোড ও কিবোর্ড নেভিগেশন সমৃদ্ধ ইউআই কিট।

### 🗄️ ফেজ ২: ব্যাকএন্ড ইঞ্জিনিয়ারিং, ডাটাবেস ডিজাইন ও এপিআই (সপ্তাহ ৪ - ৬)

#### সপ্তাহ ৪: রিলেশনাল ডাটাবেস আর্কিটেকচার (PostgreSQL & Drizzle ORM)
- **তাত্ত্বিক ভিত্তি:**
  - Relational Database Modeling: ৩য় নরমাল ফর্ম (3NF), Foreign Keys, Constraints।
  - ইনডেক্সিং ইন্টারনালস: B-Tree, GIN, GiST, এবং ইনডেক্স অপ্টিমাইজেশন (`EXPLAIN ANALYZE`)।
  - কানেকশন পুলিং (PgBouncer) ও ট্রানজ্যাকশন আইসোলেশন লেভেল (ACID Properties)।
  - Drizzle ORM বনাম Prisma: টাইপ-সেফ মাইগ্রেশন ও জিরো ওভারহেড কুয়েরি এক্সিকিউশন।
- **হ্যান্ডস-অন ল্যাব:**
  - কমপ্লেক্স রিলেশনশিপ (One-to-Many, Many-to-Many) সমৃদ্ধ ডাটাবেস স্কিমা ডিজাইন ও মাইগ্রেশন।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `scalable_postgres_schema`: অপ্টিমাইজড ইনডেক্স ও মাইগ্রেশন যুক্ত ই-কমার্স ডাটাবেস কোর।

#### সপ্তাহ ৫: হাই-পারফরম্যান্স ব্যাকএন্ড সার্ভিস (Node.js/Bun & Fastify/Hono)
- **তাত্ত্বিক ভিত্তি:**
  - Event Loop ইন্টারনালস: Microtasks, Macrotasks, Worker Threads।
  - Express বনাম Fastify বনাম Hono: রিকোয়েস্ট রাউটিং ও বেঞ্চমার্ক।
  - RESTful API বেস্ট প্র্যাকটিস ও OpenAPI/Swagger অটোমেশন।
  - সিকিউর অথেন্টিকেশন: JWT, HttpOnly Cookies, Refresh Token Rotation, OAuth2 ও Passkeys (WebAuthn)।
- **হ্যান্ডস-অন ল্যাব:**
  - Hono/Fastify দিয়ে একটি আল্ট্রা-ফাস্ট অথেন্টিকেশন মাইক্রোসার্ভিস তৈরি।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `auth_core_service`: সেশন হাইজ্যাকিং প্রতিরোধক নিরাপদ অথেন্টিকেশন ফ্রেমওয়ার্ক।

#### সপ্তাহ ৬: ডিস্ট্রিবিউটেড ক্যাশিং ও রেট লিমিটিং (Redis)
- **তাত্ত্বিক ভিত্তি:**
  - In-Memory Data Structures: Strings, Hashes, Lists, Sets, Sorted Sets, Bitmaps।
  - ক্যাশিং স্ট্র্যাটেজি: Cache-Aside, Write-Through, Write-Behind, Cache Invalidation।
  - ডিস্ট্রিবিউটেড রেট লিমিটিং: Token Bucket ও Sliding Window Log অ্যালগরিদম।
  - Redis Pub/Sub এবং Redis Streams।
- **হ্যান্ডস-অন ল্যাব:**
  - এপিআই এন্ডপয়েন্টের জন্য রিয়েল-টাইম স্লাইডিং-উইন্ডো রেট লিমিটার ও ক্যাশিং লেয়ার ইন্টিগ্রেশন।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `redis_cache_ratelimiter`: ডিডস (DDoS) ও ট্রাফিক স্পাইক প্রতিরোধক প্লাগ-অ্যান্ড-প্লে মিডলওয়্যার।

### 🌐 ফেজ ৩: রিয়েল-টাইম সিস্টেমস ও মেসেজ কিউ (সপ্তাহ ৭ - ৯)

#### সপ্তাহ ৭: দ্বি-মুখী যোগাযোগ (WebSockets & SSE)
- **তাত্ত্বিক ভিত্তি:**
  - HTTP Polling বনাম Long Polling বনাম Server-Sent Events (SSE) বনাম WebSockets।
  - WebSocket হ্যান্ডশেক প্রোটোকল, ফ্রেম স্ট্রাকচার এবং হার্টবিট/পিং-পং মেকানিজম।
  - Socket.io বনাম পিওর `ws` লাইব্রেরি বনাম PartyKit।
  - হরিজন্টাল স্কেলিং: একাধিক নোডে WebSocket সেশন পরিচালনা (Redis Adapter)।
- **হ্যান্ডস-অন ল্যাব:**
  - লো-ল্যাটেন্সি রিয়েল-টাইম চ্যাট ও নোটিফিকেশন সার্ভার তৈরি।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `realtime_collaborative_engine`: মাল্টি-ইউজার লাইভ কোলাবোরেশন ও স্টেট সিঙ্ক ইঞ্জিন।

#### সপ্তাহ ৮: অ্যাসিঙ্ক্রোনাস ব্যাকগ্রাউন্ড প্রসেসিং ও টাস্ক কিউ
- **তাত্ত্বিক ভিত্তি:**
  - কেন লং-রানিং টাস্ক সিনক্রোনাসলি রান করা অপরাধ (ব্লকিং রিকোয়েস্ট থ্রেড)।
  - মেসেজ ব্রোকার আর্কিটেকচার: BullMQ (Redis-backed), RabbitMQ, Apache Kafka।
  - টাস্ক ডিডুপ্লিকেশন, এক্সপোনেনশিয়াল ব্যাকঅফ সহ রিট্রাই মেকানিজম এবং ডেড-লেটার কিউ (DLQ)।
- **হ্যান্ডস-অন ল্যাব:**
  - ভিডিও ট্রান্সকোডিং ও রিপোর্ট জেনারেশনের জন্য BullMQ ওয়ার্কার ক্লাস্টার স্থাপন।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `async_job_processor`: অটো-রিট্রাই ও ডিএলকিউ সমৃদ্ধ ব্যাকগ্রাউন্ড জব ওয়ার্কার।

#### সপ্তাহ ৯: ফুল-টেক্সট সার্চ ও ফাইল স্টোরেজ পাইপলাইন
- **তাত্ত্বিক ভিত্তি:**
  - PostgreSQL Full-Text Search (`tsvector`, `tsquery`) বনাম Meilisearch / Elasticsearch।
  - অবজেক্ট স্টোরেজ (S3-compatible: MinIO, Cloudflare R2, AWS S3)।
  - প্রেসাইন্ড ইউআরএল (Presigned URLs): সার্ভার বাইপাস করে সরাসরি ক্লায়েন্ট থেকে সিকিউর ফাইল আপলোড।
  - মাল্টিমিডিয়া অপ্টিমাইজেশন: Sharp দিয়ে ইমেজ কম্প্রেশন ও WebP/AVIF রূপান্তর।
- **হ্যান্ডস-অন ল্যাব:**
  - Cloudflare R2 এবং Presigned URL দিয়ে সরাসরি ফাইল আপলোড ও বাংলা সার্চ ইঞ্জিন তৈরি।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `secure_media_vault`: আল্ট্রা-ফাস্ট প্রেসাইন্ড আপলোড ও সার্চ ইন্টিগ্রেশন।

### 🚀 ফেজ ৪: সিস্টেম ডিজাইন, টেস্টিং ও প্রোডাকশন ডিপ্লয়মেন্ট (সপ্তাহ ১০ - ১২)

#### সপ্তাহ ১০: স্বয়ংক্রিয় টেস্টিং ও কোয়ালিটি অ্যাসুরেন্স (QA)
- **তাত্ত্বিক ভিত্তি:**
  - Testing Pyramid: Unit Tests, Integration Tests, End-to-End (E2E) Tests।
  - টেস্ট রানার: Vitest (Lightning fast) বনাম Jest।
  - এপিআই মকিং: Mock Service Worker (MSW)।
  - ব্রাউজার অটোমেশন ও E2E টেস্টিং: Playwright দিয়ে ফুল ফ্লো ভেরিফিকেশন।
- **হ্যান্ডস-অন ল্যাব:**
  - ক্রিটিক্যাল ইউজার জার্নির (সাইনআপ -> পেমেন্ট -> ড্যাশবোর্ড) জন্য স্বয়ংক্রিয় Playwright টেস্ট স্যুট লেখা।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `e2e_playwright_testsuite`: ১০০% ক্রিটিক্যাল পাথ কভার করা অটোমেটেড টেস্ট ফ্রেমওয়ার্ক।

#### সপ্তাহ ১১: সিস্টেম ডিজাইন, স্কেলিং ও পারফরম্যান্স অপ্টিমাইজেশন
- **তাত্ত্বিক ভিত্তি:**
  - Microservices বনাম Modular Monolith: কখন কোনটি নির্বাচন করবেন।
  - লোড ব্যালেন্সিং: Round Robin, Least Connections, IP Hash।
  - রিভার্স প্রক্সি ও এপিআই গেটওয়ে: Nginx, Traefik, Caddy।
  - ডাটাবেস পার্টিশনিং ও রিড-রেপ্লিকা (Read Replicas)।
  - ওয়েব ভাইটালস (Core Web Vitals): LCP, FID/INP, CLS অপ্টিমাইজেশন।
- **হ্যান্ডস-অন ল্যাব:**
  - লোড টেস্টিং টুল (k6 / Artillery) দিয়ে সিস্টেমের ওপর ১০,০০০ কনকারেন্ট ভার্চুয়াল ইউজার রিকোয়েস্ট চালিয়ে বটলনেক বিশ্লেষণ।
- **প্রজেক্ট / ডেলিভারেবল:**
  - `k6_performance_benchmark`: এন্টারপ্রাইজ সিস্টেম ডিজাইন আর্কিটেকচার ব্লুপ্রিন্ট ও লোড টেস্ট রিপোর্ট।

#### সপ্তাহ ১২: ফাইনাল ক্যাপস্টোন প্রজেক্ট: এন্টারপ্রাইজ রিয়েল-টাইম প্ল্যাটফর্ম
- **প্রজেক্টের লক্ষ্য:**
  - একটি সম্পূর্ণ এন্টারপ্রাইজ গ্রেড ডিস্ট্রিবিউটেড ওয়েব প্ল্যাটফর্ম তৈরি করা (যেমন: Slack / Notion / Trello এর মতো রিয়েল-টাইম সিস্টেম)।
- **প্রজেক্টের মূল টেকনিক্যাল ফিচার:**
  1. Next.js App Router ফ্রন্টএন্ড + Tailwind CSS + Shadcn/UI।
  2. টাইপস্ক্রিপ্ট ও Zod দিয়ে এন্ড-টু-এন্ড টাইপ সেফটি।
  3. PostgreSQL ডাটাবেস + Drizzle ORM + PgBouncer।
  4. Redis দিয়ে রিয়েল-টাইম ক্যাশিং ও স্লাইডিং-উইন্ডো রেট লিমিটার।
  5. WebSocket দিয়ে ইনস্ট্যান্ট লাইভ মেসেজিং ও পার্টিসিপ্যান্ট প্রেজেন্স।
  6. BullMQ দিয়ে ব্যাকগ্রাউন্ড নোটিফিকেশন ও ইমেইল প্রেরক কিউ।
  7. ডকার কন্টেইনারে প্যাকেজড ও GitHub Actions দিয়ে সিআই/সিডি অটোমেশন।
- **ডেলিভারেবল:**
  - `departments/learning_paths/modern_web_capstone/`: সম্পূর্ণ সোর্স কোড রিপোজিটরি, আর্কিটেকচার ডায়াগ্রাম ও বাংলা ডিপ্লয়মেন্ট ম্যানুয়াল।
